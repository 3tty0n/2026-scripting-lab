# 担当者向け: 当日の手順

公開ページ: https://3tty0n.github.io/2026-scripting-lab/

## 授業の前に

- [ ] 公開ページを開いて、その回の「Colab で開く」を押し、ノートブックが開くことを確かめる
- [ ] 模範解答を手元で開いておく: `instructor/solutions/<回>_solution.ipynb`
- [ ] kibaco に提出箱を作る (提出物: `.ipynb` ファイル 1 つ)

## 授業 (90分)

| 時間 | すること |
|---|---|
| 20分 | スライドを見せる。コードは右側の「コードの読み方」を読み上げればよい |
| 60分 | 学生に課題を解かせる |
| 10分 | 提出のしかたを説明する (下の「学生に伝えること」) |

- 基本課題までで十分。発展は宿題にしてよい
- スライドの「付録」は授業では扱わない。質問されたときに使う

## 学生に伝えること

1. 公開ページの「Colab で開く」を押す
2. Colab で `ファイル → ドライブにコピーを保存` を押す。**これをしないと、書いた内容が消える**
3. 一番上のセルから、順に実行する
4. 各課題の `TODO` を埋める。下の確認セルが `OK` になれば正解
5. 最後に `ファイル → .ipynb をダウンロード` で保存し、kibaco に提出する

## よくある質問

| 学生の声 | 答え |
|---|---|
| 「警告: このノートブックは Google が作成したものではありません」と出る | `このまま実行` を押してよい |
| 確認セルで「名前が見つからない」と出る | 上のセルを全部実行していない。`ランタイム → 前のセルを実行` |
| 確認セルが「取得できませんでした」と出る | ネットにつながっていない。つながってから、一番上のセルをもう一度実行 |
| 書いた内容が消えた | ドライブにコピーを保存していない。最初からやり直してもらう |
| 確認セルを消した・書き換えた | 採点は別のテストで行うので、点には影響しない |
| 第8回A が遅い・止まる | `ランタイム → ランタイムのタイプを変更 → T4 GPU`。最初のモデル読み込みは数分かかる |
| Colab が使えない | 公開ページ下の「JupyterLite」を使う。保存は `File → Download` |
| 答えが分からない | 模範解答を見ながら、課題の「ヒント」の行を一緒に読む |

## 採点

kibaco の一括ダウンロードで落とした zip を、そのまま渡す。

```sh
python3 grading/grade.py 06 ~/Downloads/kibaco一括.zip --csv 結果06.csv
```

- `06` の所は回に合わせる: `06` / `07` / `08a` / `08b`
- `結果06.csv` を Excel で開くと、1 行が 1 人。`file` 列に学生のフォルダ名が入る
- 「フォーマットエラー」と出た学生は、0 点ではなく、出し直してもらう
- 第8回A はモデルを動かすので、GPU のある機械で 1 件 1〜2 分かかる。`--check-timeout 300` を付ける
- 採点器が正しく動くかは `python3 grading/grade.py 06 --check-setup` で確かめられる (配布版が 0 点、模範解答が満点なら正常)

## 注意

- `instructor/` は公開ページには出ない。模範解答を学生に渡さないこと
- JupyterLite の第8回A (WebLLM 版) は、Colab 版と課題が違う。`grade.py 08a` では採点できない
